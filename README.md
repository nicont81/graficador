# Graficador
Graficador simple de funciones lineales y cuadráticas. Generado como un único archivo HTML que incorpora CSS y JS.
Generado en un único archivo de tipo HTML y hace uso de chart.js para los gráficos estilo Matplotlib.

## Para utilizarlo se puede descargar el archivo "graficador.html" para visualizar a través de un navegador web actualizado.

Se vinculan contenidos de Laboratorio Full Stack, Programación y Matemática.
